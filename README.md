# Job Application Autopilot

A personal [Next.js](https://nextjs.org) app that tracks job applications, tailors resumes with Claude, and updates statuses from iCloud Mail.

## Running locally

Copy `.env.example` to `.env.local` and fill in the values, then:

```bash
npm install
npm run dev          # http://localhost:3000
npm run check-email  # update statuses from recent emails
```
